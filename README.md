# 📝 課題管理アプリ

大学生向けの課題管理デスクトップアプリです。  
[Flet](https://flet.dev/) を使って Python で作成しています。

---

## 主な機能

- 課題の登録（課題名・科目名・締切日・優先度）
- 完了 / 未完了の切り替え
- フィルター表示（すべて・未完了・完了済み）
- 締切が近い順に並び替え
- アプリを閉じてもデータが残る（`tasks.json` にローカル保存）

---

## 使用技術

| 項目 | 内容 |
|------|------|
| 言語 | Python 3.10+ |
| UI フレームワーク | [Flet](https://flet.dev/) 0.85+ |
| パッケージ管理 | [uv](https://docs.astral.sh/uv/) |

---

## セットアップ方法

1. **リポジトリをクローン**

   ```bash
   git clone <リポジトリのURL>
   cd flet-todo-app
   ```

2. **依存パッケージをインストール**

   ```bash
   uv sync
   ```

---

## 起動方法

```bash
uv run flet run .\src\main.py
```

---

## ファイル構成

```
flet-todo-app/
├── src/
│   └── main.py        # アプリ本体
├── pyproject.toml     # プロジェクト設定・依存パッケージ
├── uv.lock            # 依存パッケージのロックファイル
├── .gitignore
└── README.md
```

> `tasks.json` は起動後に自動生成されます（Git 管理対象外）。
